Belka

Uploads backups to cloud storage and mirrors GitHub releases.

Belka is an open-source desktop app and command-line tool for Windows and Linux. It uploads files and folders to Yandex Disk, Google Drive, Mail.ru Cloud, WebDAV servers and S3-compatible storage, skips files that are already up to date, and keeps copies of GitHub releases in the cloud. It is designed to run from a scheduler.

Belka runs entirely on your computer. It has no server of its own: files and credentials go directly between your device and your cloud provider.

По-русски

Belka — программа с открытым исходным кодом для выгрузки бэкапов в облака (Яндекс.Диск, Google Drive, Облако Mail.ru, WebDAV, S3) и зеркалирования релизов GitHub. Работает целиком на вашем компьютере, собственного сервера у неё нет. Политика конфиденциальности.
